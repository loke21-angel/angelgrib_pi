# Roadmap

- Toolbar-knap
- Fast NOAA GFS URL
- Fast Danmark/Nordsø område
- Download fil
- Send fil til GRIB-plugin

## v0.3.0 — Forecast-valg

- Nyeste run: 00/06/12/18
- Bedre filnavne med timestamp

## v0.4.0 — Enkel UI

- Lille dialog med:
  - område
  - forecast timer
  - variable
  - outputmappe
